# P.UI Package History

Package versions are independent in this monorepo. The private root and docs app
are not published.

- [@plain/ui](packages/ui/CHANGELOG.md): the complete original 0.1 and 0.2 history
  and subsequent Changesets release entries.

New publishable packages keep their own `CHANGELOG.md`. Release evidence and
migration records remain under [docs/releases](docs/releases/README.md).
