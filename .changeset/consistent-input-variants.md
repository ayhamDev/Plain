Support the shared outlined, filled, ghost and contrast input variants on PIN, search, password, tags, number, multi-select, color, file-upload and dropzone controls, SelectTrigger, Combobox, and every date/time picker and range picker. Variants style the visible control boundary, each PIN slot and both range endpoints while preserving native refs, form values, keyboard behavior and focus outlines.

Add optional field variants to CommandInput and SearchView.inputVariant, preserving their existing integrated appearance when omitted. Share variant tokens and styling across the input family, and expose matching controls and copyable source in the documentation playgrounds.
